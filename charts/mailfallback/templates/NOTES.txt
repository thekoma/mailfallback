============================================================================
2. First login
============================================================================
Default admin credentials:

    username: admin
    password: changeme

You will be forced to change the password on first login. The app image runs
database migrations automatically on startup -- no manual "alembic upgrade" step.

============================================================================
3. First boot (~30s on a fresh install)
============================================================================
On the first install the app generates the Dovecot and Roundcube config files.
The dovecot and webmail pods have an init container that WAITS for those files
(polling every 3s), so they will sit in Init until the app has written:

    /etc/dovecot/conf.d/mfb-auth.conf     (dovecot)
    /var/roundcube/config/custom.php      (webmail)

This is expected -- give it about 30 seconds on a brand-new deployment.

4. Required Secrets
============================================================================
{{- if and .Values.inlineSecrets.app.enabled .Values.inlineSecrets.roundcube.enabled }}
Secrets are chart-managed (inlineSecrets mode).
{{- else }}
This chart consumes pre-existing Secrets (it does NOT render secret material
unless inlineSecrets is enabled). Create them BEFORE / alongside install. See
the README for full "kubectl create secret generic" examples.
{{- if not .Values.inlineSecrets.app.enabled }}

--- existingSecrets.app  (Secret "{{ .Values.existingSecrets.app }}") ---
Consumed by the app AND dovecot containers. Required keys:

    MAILFALLBACK_DATABASE_URL      full SQLAlchemy URL (postgresql+psycopg://...)
    MAILFALLBACK_DB_HOST           PostgreSQL host
    MAILFALLBACK_DB_PORT           PostgreSQL port (e.g. 5432)
    MAILFALLBACK_DB_NAME           database name
    MAILFALLBACK_DB_USER           database user
    MAILFALLBACK_DB_PASSWORD       database password
    MAILFALLBACK_SECRET_KEY        Fernet key for at-rest credential encryption
    MAILFALLBACK_SESSION_SECRET    session signing secret
    MAILFALLBACK_DOVECOT_API_KEY   doveadm HTTP API key
    DOVEADM_PASSWORD               MUST equal MAILFALLBACK_DOVECOT_API_KEY

  Optional (set only if you use the feature):
    MAILFALLBACK_OIDC_*            OIDC SSO for the MFB UI
    MAILFALLBACK_WEBMAIL_OAUTH_*   Roundcube OAuth bridge
    MAILFALLBACK_GOOGLE_*          Google OAuth2 (account backup)
    MAILFALLBACK_MICROSOFT_*       Microsoft OAuth2 (account backup)
    MAILFALLBACK_METRICS_API_KEY   protects /metrics
{{- end }}
{{- if and .Values.webmail.enabled (not .Values.inlineSecrets.roundcube.enabled) }}

--- existingSecrets.roundcube  (Secret "{{ .Values.existingSecrets.roundcube }}") ---
Consumed by the webmail container. Required keys:

    ROUNDCUBEMAIL_DEFAULT_HOST     MUST be "{{ include "mailfallback.dovecotServiceName" . }}"
    ROUNDCUBEMAIL_DEFAULT_PORT     "31143"
    ROUNDCUBEMAIL_DB_*             Roundcube DB connection (rc_ prefix, shared DB)
    ROUNDCUBEMAIL_SKIN             skin name (e.g. elastic)
    ROUNDCUBEMAIL_PLUGINS          "archive,zipdownload,subscriptions_option"
    ROUNDCUBEMAIL_DES_KEY          Roundcube DES key (24 chars)
{{- end }}
{{- end }}
